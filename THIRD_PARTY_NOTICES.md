# Third-Party Notices

The skills in `skills/` were collected from several sources. Each skill keeps
the license and copyright of its original author. The MIT license in
[LICENSE](LICENSE) covers only this repository's own tooling and documentation.

## How to find a skill's license

1. A `LICENSE` or `LICENSE.txt` file inside the skill folder.
2. A `license:` field in the skill's `SKILL.md` frontmatter.
3. An `author`, `homepage` or `repository` field, or a link to the upstream
   source, in `SKILL.md` or `.claude-plugin/plugin.json`.

If none of these is present, the license is unknown. Check with the original
author before redistributing that skill.
